# Estudio Bezanilla

Sitio estático para `estudiobezanilla.cl`, desplegado en Netlify.

## Estructura

- `index.html`: página principal.
- `img/`: imágenes usadas por el sitio.
- `netlify.toml`: configuración de publicación para Netlify.

## Despliegue

Netlify debe publicar la raíz del repositorio (`.`), sin comando de build.
